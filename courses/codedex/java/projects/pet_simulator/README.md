# 🐾 Pet Simulator

This is my first Java project — a fully functional console-based pet simulator built from scratch.

The project goes beyond the basic requirements by implementing a complete game loop, interactive commands, and a stat system that changes dynamically based on user actions.


## 🎮 What I practiced

- Variables and data types
- User input handling with `Scanner`
- Conditionals (`if / else if`)
- Loops (`while`)
- Character handling (`charAt`, `toUpperCase`)
- String formatting with `.formatted()`
- Basic object-based thinking using a `Stats` structure
- Game loop logic and input validation


## 🐾 Features

- Pet creation system (name, species, gender)
- ASCII art representation based on species (Dog, Cat, Horse)
- Dynamic stat system:
  - Energy
  - Happiness
  - Skill
- Interactive command system:
  - F → Feed
  - W → Walk
  - P → Play
  - T → Train
  - C → Cuddle
  - E → Exit game
- Continuous gameplay loop with live stat updates
